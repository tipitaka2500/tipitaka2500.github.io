74. 1171 Āsavasampayutto dhammo āsavasampayuttassa dhammassa hetupaccayena paccayo— āsavasampayuttā hetū sampayuttakānaṁ khandhānaṁ hetupaccayena paccayo. (1)

1173 Āsavasampayutto dhammo āsavasampayuttassa ca āsavavippayuttassa ca dhammassa hetupaccayena paccayo— āsavasampayuttā hetū sampayuttakānaṁ khandhānaṁ cittasamuṭṭhānānañca rūpānaṁ hetupaccayena paccayo; doso sampayuttakānaṁ khandhānaṁ mohassa cittasamuṭṭhānānañca rūpānaṁ hetupaccayena paccayo.
