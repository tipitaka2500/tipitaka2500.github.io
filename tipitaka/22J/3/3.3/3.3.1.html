3.3.1 Udapānadūsakajātaka

3.3.1. อุทปานทูสกชาตก

Tikanipāta

Udapānavagga

Udapānadūsakajātaka

61. 754 “Āraññikassa isino,
cirarattatapassino;
Kicchākataṁ udapānaṁ,
kathaṁ samma avāhayi[402]”. [401]

62. 755 “Esa dhammo siṅgālānaṁ,
yaṁ pitvā ohadāmase;
Pitupitāmahaṁ dhammo,
na taṁ[403] ujjhātumarahasi”.

63. 756 “Yesaṁ vo ediso dhammo,
Adhammo pana kīdiso;
Mā vo dhammaṁ adhammaṁ vā,
Addasāma kudācanan”ti.

757 Udapānadūsakajātakaṁ paṭhamaṁ.

  1. cirarattatapassino: ciraṁ rattaṁ tapassino (syā2, syā3), cirarattaṁ tapassino (cha1) (Word Variant) ↩
  2. avāhayi: avāhasi (sī, ka-ma), apāhasi (syā2, syā3) (Word Variant) ↩
  3. taṁ: na naṁ (sī, pā1) (Word Variant) ↩
