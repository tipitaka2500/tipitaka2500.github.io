3.3.5 Rucirajātaka

3.3.5. รุจิรชาตก

Tikanipāta

Udapānavagga

Rucirajātaka

73. 770 “Kāyaṁ balākā rucirā,
kākanīḷasmimacchati;
Caṇḍo kāko sakhā mayhaṁ,
yassa cetaṁ kulāvakaṁ”. [408]

74. 771 “Nanu maṁ samma jānāsi,
dija sāmākabhojana;
Akatvā vacanaṁ tuyhaṁ,
passa lūnosmi āgato”.

75. 772 “Punapāpajjasī samma,
sīlañhi tava tādisaṁ;
Na hi mānusakā bhogā,
subhuñjā honti pakkhinā”ti.

773 Rucirajātakaṁ pañcamaṁ.
