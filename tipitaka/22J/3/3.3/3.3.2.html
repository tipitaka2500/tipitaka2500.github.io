3.3.2 Byagghajātaka

3.3.2. พ๎ยัค์ฆชาตก

Tikanipāta

Udapānavagga

Byagghajātaka

64. 758 “Yena mittena saṁsaggā,
yogakkhemo vihiyyati;
Pubbevajjhābhavaṁ tassa,
rukkhe akkhīva paṇḍito.

65. 759 Yena mittena saṁsaggā,
yogakkhemo pavaḍḍhati;
Kareyyattasamaṁ vuttiṁ,
sabbakiccesu paṇḍito”.

66. 760 “Etha byagghā nivattavho,
Paccupetha mahāvanaṁ;
Mā vanaṁ chindi nibyagghaṁ,
Byagghā māhesu nibbanā”ti. [404] [405]

761 Byagghajātakaṁ dutiyaṁ.

  1. Paccupetha: paccametha (sī, pā1) (Word Variant) ↩
  2. Mā: mā no (syā2, syā3) (Word Variant) ↩
