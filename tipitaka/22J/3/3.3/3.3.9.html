3.3.9 Satapattajātaka

3.3.9. สตปัต์ตชาตก

Tikanipāta

Udapānavagga

Satapattajātaka

85. 786 “Yathā māṇavako panthe,
siṅgāliṁ vanagocariṁ;
Atthakāmaṁ pavedentiṁ[422],
anatthakāmāti maññati;
Anatthakāmaṁ satapattaṁ,
atthakāmoti maññati.

86. 787 Evameva idhekacco,
puggalo hoti tādiso;
Hitehi vacanaṁ vutto,
paṭigaṇhāti vāmato.

87. 788 Ye ca kho naṁ pasaṁsanti,
bhayā ukkaṁsayanti vā[423];
Tañhi so maññate mittaṁ,
satapattaṁva māṇavo”ti.

789 Satapattajātakaṁ navamaṁ.

  1. pavedentiṁ: pavedenti (syā2, syā3), pavadantiṁ (pā1) (Word Variant) ↩
  2. vā: ca (sī, pā1) (Word Variant) ↩
