3.3.3 Kacchapajātaka

3.3.3. กัจ์ฉปชาตก

Tikanipāta

Udapānavagga

Kacchapajātaka

67. 762 “Ko nu uddhitabhattova[406],
pūrahatthova brāhmaṇo;
Kahaṁ nu bhikkhaṁ acari,
kaṁ saddhaṁ upasaṅkami”.

68. 763 “Ahaṁ kapismi dummedho,
anāmāsāni āmasiṁ;
Tvaṁ maṁ mocaya bhaddaṁ te,
mutto gaccheyya pabbataṁ”.

69. 764 “Kacchapā kassapā honti,
Koṇḍaññā honti makkaṭā;
Muñca kassapa koṇḍaññaṁ,
Kataṁ methunakaṁ tayā”ti. [407]

765 Kacchapajātakaṁ tatiyaṁ.

  1. uddhitabhattova: udditabhattova (sī), vaḍḍhitabhattova (syā2, syā3) (Word Variant) ↩
  2. Kataṁ: kathaṁ (ka-ma) (Word Variant) ↩
