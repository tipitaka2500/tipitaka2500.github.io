3.3.7. ทสํคสุต์ต

Dhātusaṃyutta

Kammapathavagga

Dasaṅgasutta

113. 780 Sāvatthiyaṁ viharati. “Dhātusova, bhikkhave, sattā saṁsandanti samenti. Micchādiṭṭhikā micchādiṭṭhikehi saddhiṁ saṁsandanti samenti; micchāsaṅkappā…pe… micchāvācā… micchākammantā… micchāājīvā… micchāvāyāmā… micchāsatino… micchāsamādhino micchāsamādhīhi saddhiṁ saṁsandanti samenti; micchāñāṇino micchāñāṇīhi saddhiṁ saṁsandanti samenti; micchāvimuttino micchāvimuttīhi saddhiṁ saṁsandanti samenti.

781 Sammādiṭṭhikā sammādiṭṭhikehi saddhiṁ saṁsandanti samenti; sammāsaṅkappā…pe… sammāvācā… sammākammantā… sammāājīvā… sammāvāyāmā… sammāsatino… sammāsamādhino… sammāñāṇino sammāñāṇīhi saddhiṁ saṁsandanti samenti; sammāvimuttino sammāvimuttīhi saddhiṁ saṁsandanti samentī”ti.

782 Sattamaṁ.
