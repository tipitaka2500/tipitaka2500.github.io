3.3.14 Vicāralakkhaṇapañha

3.3.14. วิจารลัก์ขณปัญ๎ห

Milindapañha

Vicāravagga

Vicāralakkhaṇapañha

62. 309 “Bhante nāgasena, kiṁlakkhaṇo vicāro”ti? “Anumajjanalakkhaṇo, mahārāja, vicāro”ti.

310 “Opammaṁ karohī”ti. “Yathā, mahārāja, kaṁsathālaṁ ākoṭitaṁ pacchā anuravati anusandahati[87], yathā, mahārāja, ākoṭanā, evaṁ vitakko daṭṭhabbo. Yathā anuravanā[88], evaṁ vicāro daṭṭhabbo”ti.

311 “Kallosi, bhante nāgasenā”ti.

312 Vicāralakkhaṇapañho cuddasamo.

313 Vicāravaggo tatiyo.

314 Imasmiṁ vagge cuddasa pañhā.

  1. anusandahati: anusandhahati (maku), anusaddāyati (ka-ma) (Word Variant) ↩
  2. anuravanā: anuravano (maku), anumajjanā (ka-ma) (Word Variant) ↩
