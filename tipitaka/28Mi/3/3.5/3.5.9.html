3.5.9 Uppajjatijānanapañha

3.5.9. อุป์ปัช์ชติชานนปั๎ห

Milindapañha

Buddhavagga

Uppajjatijānanapañha

81. 387 Rājā āha— “bhante nāgasena, yo uppajjati, jānāti so ‘uppajjissāmī’”ti? “Āma, mahārāja, yo uppajjati jānāti so ‘uppajjissāmī’”ti.

388 “Opammaṁ karohī”ti. “Yathā, mahārāja, kassako gahapatiko bījāni pathaviyaṁ nikkhipitvā sammā deve vassante jānāti ‘dhaññaṁ nibbattissatī’”ti? “Āma, bhante, jāneyyā”ti. “Evameva kho, mahārāja, yo uppajjati, jānāti so ‘uppajjissāmī’”ti.

389 “Kallosi, bhante nāgasenā”ti.

390 Uppajjatijānanapañho[112] navamo.
