1.5.7 Methunasutta

1.5.7. เมถุนสุต์ต

Paṭhamapaṇṇāsaka

Mahāyaññavagga

Methunasutta

50. 278 Atha kho jāṇussoṇi brāhmaṇo yena bhagavā tenupasaṅkami; upasaṅkamitvā bhagavatā saddhiṁ sammodi. Sammodanīyaṁ kathaṁ sāraṇīyaṁ vītisāretvā ekamantaṁ nisīdi. Ekamantaṁ nisinno kho jāṇussoṇi brāhmaṇo bhagavantaṁ etadavoca— “bhavampi no gotamo brahmacārī paṭijānātī”ti? “Yañhi taṁ, brāhmaṇa, sammā vadamāno vadeyya— ‘akhaṇḍaṁ acchiddaṁ asabalaṁ akammāsaṁ paripuṇṇaṁ parisuddhaṁ brahmacariyaṁ caratī’ti, mameva taṁ, brāhmaṇa, sammā vadamāno vadeyya— ‘ahañhi, brāhmaṇa, akhaṇḍaṁ acchiddaṁ asabalaṁ akammāsaṁ paripuṇṇaṁ parisuddhaṁ brahmacariyaṁ carāmī’”ti. “Kiṁ pana, bho gotama, brahmacariyassa khaṇḍampi chiddampi sabalampi kammāsampī”ti?

279 “Idha, brāhmaṇa, ekacco samaṇo vā brāhmaṇo vā sammā brahmacārī paṭijānamāno na heva kho mātugāmena saddhiṁ dvayaṁdvayasamāpattiṁ samāpajjati; api ca kho mātugāmassa ucchādanaparimaddananhāpanasambāhanaṁ sādiyati. So taṁ assādeti[87], taṁ nikāmeti, tena ca vittiṁ āpajjati. Idampi kho, brāhmaṇa, brahmacariyassa khaṇḍampi chiddampi sabalampi kammāsampi. Ayaṁ vuccati, brāhmaṇa, aparisuddhaṁ brahmacariyaṁ carati, saṁyutto methunena saṁyogena na parimuccati jātiyā jarāya maraṇena[88] sokehi paridevehi dukkhehi domanassehi upāyāsehi, na parimuccati dukkhasmāti vadāmi. (1)

280 Puna caparaṁ, brāhmaṇa, idhekacco samaṇo vā brāhmaṇo vā sammā brahmacārī paṭijānamāno na heva kho mātugāmena saddhiṁ dvayaṁdvayasamāpattiṁ samāpajjati, napi mātugāmassa ucchādanaparimaddananhāpanasambāhanaṁ sādiyati; api ca kho mātugāmena saddhiṁ sañjagghati saṅkīḷati saṅkelāyati…pe… . (2)

281 Napi mātugāmena saddhiṁ sañjagghati saṅkīḷati saṅkelāyati; api ca kho mātugāmassa cakkhunā cakkhuṁ upanijjhāyati pekkhati…pe… . (3)

282 Napi mātugāmassa cakkhunā cakkhuṁ upanijjhāyati pekkhati; api ca kho mātugāmassa saddaṁ suṇāti tirokuṭṭaṁ vā tiropākāraṁ vā hasantiyā vā bhaṇantiyā vā gāyantiyā vā rodantiyā vā…pe… . (4)

283 Napi mātugāmassa saddaṁ suṇāti tirokuṭṭaṁ vā tiropākāraṁ vā hasantiyā vā bhaṇantiyā vā gāyantiyā vā rodantiyā vā; api ca kho yānissa tāni pubbe mātugāmena saddhiṁ hasitalapitakīḷitāni tāni anussarati…pe… . (5)

284 Napi yānissa tāni pubbe mātugāmena saddhiṁ hasitalapitakīḷitāni tāni anussarati; api ca kho passati gahapatiṁ vā gahapatiputtaṁ vā pañcahi kāmaguṇehi samappitaṁ samaṅgībhūtaṁ paricārayamānaṁ…pe… . (6)

285 Napi passati gahapatiṁ vā gahapatiputtaṁ vā pañcahi kāmaguṇehi samappitaṁ samaṅgībhūtaṁ paricārayamānaṁ; api ca kho aññataraṁ devanikāyaṁ paṇidhāya brahmacariyaṁ carati imināhaṁ sīlena vā vatena vā tapena vā brahmacariyena vā devo vā bhavissāmi devaññataro vāti. So taṁ assādeti, taṁ nikāmeti, tena ca vittiṁ āpajjati. Idampi kho, brāhmaṇa, brahmacariyassa khaṇḍampi chiddampi sabalampi kammāsampi. Ayaṁ vuccati, brāhmaṇa, aparisuddhaṁ brahmacariyaṁ carati saṁyutto methunena saṁyogena, na parimuccati jātiyā jarāya maraṇena sokehi paridevehi dukkhehi domanassehi upāyāsehi, na parimuccati dukkhasmāti vadāmi. (7)

286 Yāvakīvañcāhaṁ, brāhmaṇa, imesaṁ sattannaṁ methunasaṁyogānaṁ aññataraññataramethunasaṁyogaṁ[89] attani appahīnaṁ samanupassiṁ, neva tāvāhaṁ, brāhmaṇa, sadevake loke samārake sabrahmake sassamaṇabrāhmaṇiyā pajāya sadevamanussāya anuttaraṁ sammāsambodhiṁ abhisambuddhoti paccaññāsiṁ[90].

287 Yato ca khohaṁ, brāhmaṇa, imesaṁ sattannaṁ methunasaṁyogānaṁ aññataraññataramethunasaṁyogaṁ attani appahīnaṁ na samanupassiṁ, athāhaṁ, brāhmaṇa, sadevake loke samārake sabrahmake sassamaṇabrāhmaṇiyā pajāya sadevamanussāya anuttaraṁ sammāsambodhiṁ abhisambuddhoti paccaññāsiṁ. ‘Ñāṇañca pana me dassanaṁ udapādi, akuppā me vimutti[91], ayamantimā jāti, natthi dāni punabbhavo’”ti.

288 Evaṁ vutte, jāṇussoṇi brāhmaṇo bhagavantaṁ etadavoca— “abhikkantaṁ, bho gotama, abhikkantaṁ, bho gotama…pe… upāsakaṁ maṁ bhavaṁ gotamo dhāretu ajjatagge pāṇupetaṁ saraṇaṁ gatan”ti.

289 Sattamaṁ.

  2. maraṇena: jarāmaraṇena (sī, syā1-3, pā1) (Word Variant) ↩

  4. paccaññāsiṁ: abhisambuddho paccaññāsiṁ (sī, syā1-3, pā1) (Word Variant) ↩
