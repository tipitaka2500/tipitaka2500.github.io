3.3.11. เอกาทสมสุต์ต

Tatiyapaṇṇāsaka

Parisuddhavagga

Ekādasamasutta

133. 1102 “Dasayime, bhikkhave, sammattā. Katame dasa? Sammādiṭṭhi, sammāsaṅkappo, sammāvācā, sammākammanto, sammāājīvo, sammāvāyāmo, sammāsati, sammāsamādhi, sammāñāṇaṁ, sammāvimutti— ime kho, bhikkhave, dasa sammattā”ti.

1103 Ekādasamaṁ.

1104 Parisuddhavaggo[237] tatiyo.
