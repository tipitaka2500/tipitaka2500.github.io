3.3.7. สัต์ตมสุต์ต

Tatiyapaṇṇāsaka

Parisuddhavagga

Sattamasutta

129. 1094 “Dasayime, bhikkhave, dhammā bhāvitā bahulīkatā mahapphalā honti mahānisaṁsā, nāññatra sugatavinayā. Katame dasa? Sammādiṭṭhi…pe… sammāvimutti— ime kho, bhikkhave, dasa dhammā bhāvitā bahulīkatā mahapphalā honti mahānisaṁsā, nāññatra sugatavinayā”ti.
