3.3.1. ปมสุต์ต

Tatiyapaṇṇāsaka

Parisuddhavagga

Paṭhamasutta

123. 1082 [236] “Dasayime, bhikkhave, dhammā parisuddhā pariyodātā, nāññatra sugatavinayā. Katame dasa? Sammādiṭṭhi, sammāsaṅkappo, sammāvācā, sammākammanto, sammāājīvo, sammāvāyāmo, sammāsati, sammāsamādhi, sammāñāṇaṁ, sammāvimutti— ime kho, bhikkhave, dasa dhammā parisuddhā pariyodātā, nāññatra sugatavinayā”ti.

1083 Paṭhamaṁ.
