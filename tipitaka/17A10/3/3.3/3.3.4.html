3.3.4. จตุต์ถสุต์ต

Tatiyapaṇṇāsaka

Parisuddhavagga

Catutthasutta

126. 1088 “Dasayime, bhikkhave, dhammā rāgavinayapariyosānā honti dosavinayapariyosānā honti mohavinayapariyosānā honti, nāññatra sugatavinayā. Katame dasa? Sammādiṭṭhi…pe… sammāvimutti— ime kho, bhikkhave, dasa dhammā rāgavinayapariyosānā honti dosavinayapariyosānā honti mohavinayapariyosānā honti, nāññatra sugatavinayā”ti.

1089 Catutthaṁ.
