3.3.8. อัฏ์ฐมสุต์ต

Tatiyapaṇṇāsaka

Parisuddhavagga

Aṭṭhamasutta

130. 1096 “Dasayime, bhikkhave, dhammā bhāvitā bahulīkatā rāgavinayapariyosānā honti dosavinayapariyosānā honti mohavinayapariyosānā honti, nāññatra sugatavinayā. Katame dasa? Sammādiṭṭhi…pe… sammāvimutti— ime kho, bhikkhave, dasa dhammā bhāvitā bahulīkatā rāgavinayapariyosānā honti dosavinayapariyosānā honti mohavinayapariyosānā honti, nāññatra sugatavinayā”ti.

1097 Aṭṭhamaṁ.
