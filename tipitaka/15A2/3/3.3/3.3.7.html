Tatiyapaṇṇāsaka

Dānavagga

148. 239 “Dveme, bhikkhave, saṁvibhāgā. Katame dve? Āmisasaṁvibhāgo ca dhammasaṁvibhāgo ca. Ime kho, bhikkhave, dve saṁvibhāgā. Etadaggaṁ, bhikkhave, imesaṁ dvinnaṁ saṁvibhāgānaṁ yadidaṁ dhammasaṁvibhāgo”ti.
