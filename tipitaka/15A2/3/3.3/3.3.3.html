Dānavagga

144. 235 “Dveme, bhikkhave, cāgā. Katame dve? Āmisacāgo ca dhammacāgo ca. Ime kho, bhikkhave, dve cāgā. Etadaggaṁ, bhikkhave, imesaṁ dvinnaṁ cāgānaṁ yadidaṁ dhammacāgo”ti.
