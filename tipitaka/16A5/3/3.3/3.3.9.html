3.3.9 Parikuppasutta

3.3.9. ปริกุป์ปสุต์ต

Tatiyapaṇṇāsaka

Gilānavagga

Parikuppasutta

129. 725 “Pañcime, bhikkhave, āpāyikā nerayikā parikuppā atekicchā. Katame pañca? Mātā[318] jīvitā voropitā hoti, pitā[319] jīvitā voropito[320] hoti, arahaṁ[321] jīvitā voropito hoti, tathāgatassa duṭṭhena cittena lohitaṁ uppāditaṁ hoti, saṁgho bhinno hoti. Ime kho, bhikkhave, pañca āpāyikā nerayikā parikuppā atekicchā”ti.

726 Navamaṁ.

  1. Mātā: mātaraṁ (ka-ma) (Word Variant) ↩
  2. pitā: pitaraṁ (ka-ma) (Word Variant) ↩
  3. voropito: voropitā (ka-ma) (Word Variant) ↩
  4. arahaṁ: arahā (syā1-3), arahantaṁ (ka-ma) (Word Variant) ↩
