3.1.2. อุส์สํกิตสุต์ต

Tatiyapaṇṇāsaka

Phāsuvihāravagga

Ussaṅkitasutta

102. 615 [275] “Pañcahi, bhikkhave, dhammehi samannāgato bhikkhu ussaṅkitaparisaṅkito hoti pāpabhikkhūti api akuppadhammopi[276].

616 [277] Katamehi pañcahi? Idha, bhikkhave, bhikkhu vesiyāgocaro vā hoti, vidhavāgocaro vā hoti, thullakumārikāgocaro vā hoti, paṇḍakagocaro vā hoti, bhikkhunīgocaro vā hoti.

617 Imehi kho, bhikkhave, pañcahi dhammehi samannāgato bhikkhu ussaṅkitaparisaṅkito hoti pāpabhikkhūti api akuppadhammopī”ti.

618 Dutiyaṁ.

  1. saṅkitasuttaṁ (sī) (Word Variant) ↩
  2. akuppadhammopi: api akuppadhammo (sī, syā1-3, kaṃ), api kuppadhammopi (pā1) (Word Variant) ↩
